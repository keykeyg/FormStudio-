Form Studio 1.1 — 2026-10-24 (review and repair by Claude)
Fixed:
- Static files served with explicit types (Windows registry can map .js to text/plain, which blanks the page).
- Runner guard read fields the runner doesn't write; now uses run_night.pid (live process check, never os.kill on Windows), recent receipts' feature_state, and the scheduled task.
- Qwen thinking switched off per request (runner's NO_THINK), so the reply budget goes to code.
- Reply protocol: message + one ```python block; JSON still accepted (strict=False for raw newlines); truncated code is retried.
- CadQuery allowlist: added slot2D, offset2D, sketch API, polarLine, each, append/extend, bounding-box fields and similar common calls.
- Failed or stopped chat turns now add an assistant note, so roles stay alternating.
- Static/image MIME types no longer depend on the Windows registry.
Added: Load model (runner's settings via lms), Stop (closes the socket even during prompt processing), Quit, single-instance app window (Chrome/Edge --app), desktop + Start menu shortcuts via Install-Form-Studio.cmd, app icon, error dialog/log when started without a console.
